# CollateralSafe – On-Chain Collateral Locking System

CollateralSafe allows users to lock their tokens as collateral to secure lending, leasing,
or conditional agreements, ensuring funds remain protected until obligations are fulfilled.

## Core Capabilities
- Lock STX or tokens as collateral
- Release funds only after approval/settlement
- Borrower and lender dispute safeguards
- Transparent collateral state tracking

## Key Functions
lock-collateral, release-collateral, seize-collateral, get-position, get-locked-amount
